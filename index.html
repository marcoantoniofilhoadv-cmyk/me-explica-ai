Me Explica Aí Publisher

Ferramenta pessoal usada pelo criador do canal Me Explica Aí (YouTube @Me-explica-ai-01) para enviar os próprios vídeos ao YouTube. Não é um serviço aberto ao público.

Política de privacidade

Última atualização: 19 de novembro de 2026.

  • Quem usa: apenas o dono do canal Me Explica Aí, na própria conta Google.
  • Dados acessados: com a permissão do dono, o app usa a API do YouTube para enviar vídeos (escopo youtube.upload) e para confirmar qual canal está conectado (escopo youtube.readonly).
  • Armazenamento: o token de acesso fica guardado só no computador do dono. Nenhum dado é enviado a terceiros, vendido ou usado para publicidade.
  • Revogar acesso: a qualquer momento em myaccount.google.com/permissions.
  • O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
